# CV / Resume Files

This folder contains Jazmin Rodriguez's curriculum vitae in both English and Spanish.

## Required Files

Please add the following PDF files to this directory:
- `jazmin-rodriguez-cv-en.pdf` - English version
- `jazmin-rodriguez-cv-es.pdf` - Spanish version (Versión en español)

## Usage

These PDFs are automatically served based on the user's selected language in the website:
- When language is set to English → `jazmin-rodriguez-cv-en.pdf`
- When language is set to Spanish → `jazmin-rodriguez-cv-es.pdf`

The download button in the navigation sidebar will automatically switch between these files based on the active language.

## Update Instructions

To update the CV:
1. Replace the corresponding PDF file(s)
2. Keep the same filename to maintain the download link
3. Ensure both versions are up-to-date
