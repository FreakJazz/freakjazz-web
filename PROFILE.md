### 🛠️ Tech Stack

**Frontend:**

- React 19.1.0 + TypeScript 5.8.3
- Material-UI v7 (latest design system)
- Framer Motion (smooth animations)
- React Router v7 (modern navigation)
- i18next (English/Spanish support)

**Backend & Services:**

- Vercel Serverless Functions
- Mailjet Email API
- JWT Authentication
- Node.js 22.x

**SEO & Analytics:**

- Google Tag Manager (GTM-5PF9FPTK)
- Schema.org structured data (Person, Service, Organization)
- Dynamic meta tags with react-helmet-async
- Sitemap.xml & robots.txt
- Hreflang tags for multilingual SEO
- Google Search Console verification

**Build & DevOps:**

- Vite 6.3.5 (ultra-fast HMR)
- ESLint + Prettier (code quality)
- TypeScript strict mode
- Vercel deployment
- Automated builds & CI/CD

### ✨ Key Features

- 🔍 **SEO Optimized**: Complete technical SEO implementation with GTM, structured data, and multilingual support
- 🌐 **Bilingual**: Full internationalization (English/Spanish) with automatic language detection
- 📧 **Quote System**: Serverless contact form with email notifications via Mailjet
- 🎨 **Modern UI**: Material-UI v7 with custom theme and dark mode support
- 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop
- ⚡ **High Performance**: Lighthouse score 90+ with optimized assets and lazy loading
- 🔐 **Secure**: JWT authentication, HTTPS, CORS protection
- ♿ **Accessible**: WCAG 2.1 compliant with semantic HTML

### 📈 Recent Achievements (May 2026)

- ✅ Implemented comprehensive SEO strategy with Google services
- ✅ Reduced initial bundle size by 40% (removed unused auth libraries, charts, editors)
- ✅ Achieved perfect TypeScript compilation (0 errors)
- ✅ Integrated analytics tracking with custom GTM events
- ✅ Optimized navigation UX with centered alignment and proper link handling

### 🗑️ Optimization: Removed Unused Modules

To maintain a lean, performant codebase, the following modules from the original Minimal template were removed:

- **Authentication**: Firebase, Supabase, Auth0, AWS Amplify (kept only JWT)
- **Visualization**: ApexCharts, React ApexCharts
- **Mapping**: Mapbox GL integration
- **Editors**: TipTap WYSIWYG, React Markdown
- **Calendar**: FullCalendar system
- **Data Grid**: MUI X Data Grid
- **UI Components**: Carousel, Lightbox, Org Chart, Phone Input, Date Range Picker, Mega Menu

**Result**: ~60% reduction in node_modules size, faster builds, easier maintenance
