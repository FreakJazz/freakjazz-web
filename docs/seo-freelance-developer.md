## 🔍 GOOGLE SEARCH CONSOLE

### Setup Paso a Paso

#### 1. Verificación del Sitio

**Método recomendado: HTML Tag**

Agregar al `<head>` de tu sitio:

```html
<meta name="google-site-verification" content="TU_CÓDIGO_AQUÍ" />
```

**Pasos:**

1. Ir a https://search.google.com/search-console
2. Click "Add Property" → "URL prefix"
3. Ingresar: `https://freakjazz.com`
4. Seleccionar método "HTML tag"
5. Copiar el código de verificación
6. Agregar al componente SEO
7. Deploy del sitio
8. Click "Verify" en Search Console

#### 2. Enviar Sitemap

```
URL del sitemap: https://freakjazz.com/sitemap.xml
```

**En Search Console:**

1. Sidebar → Sitemaps
2. "Add a new sitemap"
3. Ingresar: `sitemap.xml`
4. Submit

#### 3. Solicitar Indexación

**Para páginas importantes:**

1. Ir a "URL Inspection"
2. Ingresar la URL: `https://freakjazz.com/cotizacion`
3. Click "Request Indexing"

**URLs prioritarias para indexar:**

- `https://freakjazz.com/` (home)
- `https://freakjazz.com/cotizacion` (quote form)
- `https://freakjazz.com/about-us` (about)

4. Enhanced measurement: ON (scroll, clicks, downloads, video)

**Obtendrás:**

- **Measurement ID:** `G-XXXXXXXXXX` (necesario para el código)

#### 3. Código de Tracking

```typescript
// src/lib/google-analytics.ts

export const GA_MEASUREMENT_ID = import.meta.env.VITE_GA_MEASUREMENT_ID || 'G-XXXXXXXXXX';

// Cargar el script de Google Analytics
export const loadGoogleAnalytics = () => {
  if (typeof window === 'undefined') return;

  // Script principal
  const script = document.createElement('script');
  script.src = `https://www.googletagmanager.com/gtag/js?id=${GA_MEASUREMENT_ID}`;
  script.async = true;
  document.head.appendChild(script);

  // Configuración
  window.dataLayer = window.dataLayer || [];
  function gtag(...args: any[]) {
    window.dataLayer.push(args);
  }
  gtag('js', new Date());
  gtag('config', GA_MEASUREMENT_ID, {
    page_path: window.location.pathname,
  });
};

// Tracking de eventos
export const trackEvent = (eventName: string, eventParams?: Record<string, any>) => {
  if (typeof window === 'undefined') return;

  window.gtag?.('event', eventName, eventParams);
};

// Tracking de pageviews (para SPA)
export const trackPageView = (url: string) => {
  if (typeof window === 'undefined') return;

  window.gtag?.('config', GA_MEASUREMENT_ID, {
    page_path: url,
  });
};
```

#### 4. Eventos Personalizados

```typescript
// src/sections/quote/quote-form-detailed.tsx

import { trackEvent } from 'src/lib/google-analytics';

const onSubmit = async (data: QuoteFormData) => {
  try {
    // ... existing code

    // Track form submission
    trackEvent('quote_form_submit', {
      company_type: data.companyType,
      solution_type: data.solutionType,
      budget_range: data.budget,
      industry: data.industry,
    });

    // Track successful submission
    trackEvent('quote_form_success', {
      lead_source: 'website',
    });
  } catch (error) {
    // Track error
    trackEvent('quote_form_error', {
      error_message: error.message,
    });
  }
};
```

#### 5. Configurar Conversiones en GA4

**En Google Analytics:**

1. Admin → Events
2. Click "Create event" o "Mark as conversion"
3. Marcar estos eventos como conversiones:
   - `quote_form_success`
   - `contact_form_submit`
